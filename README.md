# WordPress & Web Build Checklist

A reusable checklist for planning, building, and launching a business website. Adapt it to the goals and requirements of each project. These are general practices, not a substitute for project-specific security, legal, or accessibility review.

## 1. Plan and content

- Define the intended audience, site goals, primary calls to action, and required pages before implementation.
- Organize content with clear page titles, concise sections, and logical headings.
- Make contact paths and important next steps easy to find.

## 2. Mobile-first layout

- Design for small screens first, then check tablet and desktop layouts.
- Test navigation, menus, forms, buttons, and any interactive elements at common screen sizes.
- Check that text is readable, tap targets are usable, and content does not require horizontal scrolling.
- Test on touch devices and across major browsers where possible.

## 3. WordPress foundations

- Choose a maintained theme and reputable plugins that fit the site’s requirements.
- Keep WordPress core, themes, and plugins updated; use a staging environment for significant changes.
- Limit plugins to needed features and document important configuration.
- Set up regular backups and confirm that a restore can be completed.

## 4. HTTPS (SSL) and security

- Confirm the site loads over HTTPS with a valid certificate and no browser security warnings.
- Redirect HTTP traffic to HTTPS and check for mixed-content issues.
- Use strong, unique administrator passwords and multi-factor authentication where available.
- Give each account only the access it needs; remove unused accounts and extensions.
- Keep software current and protect backup files and credentials.

## 5. SEO basics

- Write a unique, descriptive page title and meta description for each important page.
- Use one clear main heading per page and a logical heading hierarchy.
- Use readable URLs, descriptive internal links, and relevant page-to-page links.
- Add useful alternative text to informative images; keep decorative images from adding noise.
- Review the XML sitemap and robots.txt so important pages can be discovered and are not accidentally blocked.
- Keep local business details consistent when local search is relevant; use structured data only when it accurately describes the page.
- Do not promise rankings or add unverified claims, reviews, or business details.

## 6. Quality checks before launch

- Optimize image file sizes and review page loading on mobile connections.
- Test every link, form, click-to-call link, and email link; confirm expected success and error states.
- Check keyboard navigation, visible focus, form labels, color contrast, and image alternatives.
- Review page titles, spelling, 404 handling, and HTTPS behavior on the live site.
- Confirm backups and the handoff steps for future updates.
